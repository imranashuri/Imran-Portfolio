# Imran-Portfolio
This is my personal portfolio
 ## Personal Portfolio Website

 Project Overview

I developed a personal portfolio website to showcase my skills, projects, and professional information in a clean and modern design. The portfolio includes a responsive navigation bar, a hero section with an introduction, a featured projects section, an about section, and a contact footer.

## Frontend Development

For the frontend development, I used HTML5 to structure the website and CSS3 to design and style the interface. I applied responsive layout techniques, hover effects, transitions, image cards, and modern typography to improve the overall user experience and visual appearance.

## Features of the Portfolio

* Responsive navigation menu
* Interactive hover effects
* Project cards with images and descriptions
* Clean UI/UX design
* Contact and social profile section
* Mobile-friendly layout

## Tools and Technologies Used

* HTML5
* CSS3
* Google Fonts
* Unsplash Images
* Visual Studio Code (VS Code)
* GitHub for project hosting and version control

## Learning Outcome

This project helped me improve my frontend development skills, especially in responsive web design, styling, and layout structuring.
